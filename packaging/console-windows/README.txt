Guardian 3.0 console
====================

guardian-console.exe is the teacher's window. It runs on Windows 10 and 11
(32 and 64 bit) without administrator rights.

- "Connect to a server": the address of your Guardian server and, for a
  self-signed certificate, its SHA-256 (from the server's log).
- "Run the server on this computer": the console starts the server itself while
  it is open; the student computers find this computer by name.

Rooms, profiles, computers and users are managed from the console. "Connection
info..." gives the command that installs the agent on a student computer.

When the server cannot be reached, "Local fallback..." lets teachers switch a
room's profile directly over the school network (enable it once per computer
while the server is reachable).
